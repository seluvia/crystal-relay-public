v3.1.9 beta 5 (shipped — rolled into v3.1.9 stable)

v3.1.9 beta 4 (shipped — rolled into v3.1.9 stable)
Added:
- Float action modes for channel point rewards with Float parameter type: Set (existing), Random, Add, Subtract, Add/Subtract, Multiply, Toggle, Cycle, Glitchy, and Pulse. Random picks a value in a configurable min/max range. Add and Subtract adjust the current avatar value by a configurable amount. Add/Subtract picks a direction each time. Multiply scales the current value by a factor (with optional clamp). Toggle switches between two user-defined values. Cycle increments by a step and wraps at max. Glitchy continuously re-rolls random values during the active time. Pulse sends the value and restores after a short configurable delay (independent of Active Time).
Changed:
- "Add amount to active time" now always adds Active Time + scaled amount on every matching Bits or Subs trigger instead of only on the first trigger; cap still limits total running time.
- Renamed "Scale active time by amount" to "Add amount to active time" in the Bits and Subs override time-settings popup.
- Added "Add bits time to swap" toggle in the per-avatar Bits and Subs settings of the Avatar Swap manager. The toggle is independent of the global "Add amount to active time" toggle and controls whether bits and subs events extend the running avatar swap (when on) or only the fixed Active Time runs (when off).
- Renamed the per-avatar Subs trigger toggle from "Add bits time to swap" to "Add sub time to swap".
- Added a shared max-time cap on the per-avatar Avatar Swap manager. The cap is stored on the avatar profile and is shown in both the Bits and Subs rule editors. Editing one updates the other. The T1/T2/T3 inputs in the Subs editor are now hidden when the new toggle is off.
- Renamed "Scale active time by amount" to "Add amount to active time" in the Bits and Subs override time-settings popup.
- Avatar Set Float redeem: split the single `FloatTransitionSeconds` field into `FloatTransitionInSeconds` and `FloatTransitionOutSeconds`. The transition now applies to every Float avatar parameter redeem (timed, instant, and all action modes including Glitchy), so values smoothly glide to and from the target. Old saves migrate: the legacy `FloatTransitionSeconds` value copies into both new fields on first load and is then dropped from the save file.
